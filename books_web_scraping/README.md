# Парсинг каталога e-commerce и факторный анализ цен интернет-магазина

Автоматизированный сквозной сбор данных онлайн-каталога книг (1 000 товаров с 50 страниц), очистка данных регулярными выражениями и исследовательский статистический анализ взаимосвязи стоимости и рейтингов.

**Источник данных:** [Books to Scrape](http://books.toscrape.com/)  
**Инструменты и стек:** Python, Requests, BeautifulSoup4, Pandas, NumPy, Matplotlib, Seaborn, OpenPyXL, RegEx  
**Выходные форматы:** `.csv`, `.xlsx`

---

## Задачи проекта

1. Реализация парсера с обработкой пагинации на 50 страниц и защитой от блокировок (`User-Agent`, паузы `time.sleep`).
2. Очистка и предобработка данных: конвертация цен из валютной строки в `float`, трансформация текстовых рейтингов в шкалу от 1 до 5.
3. Эксплораторный анализ данных (EDA): расчет квантилей, поиск аномалий, расчет мер центральной тенденции.
4. Визуализация распределений и взаимосвязи признаков (гистограммы, `boxplot`, `countplot`).
